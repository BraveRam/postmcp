# postmcp

The Postman for MCP. Turn any OpenAPI spec into a context-optimized MCP server in seconds.

## Quickstart

```bash
# Launch interactive web studio
postmcp studio

# Inspect an API spec
postmcp inspect @stripe

# Run live MCP server
postmcp run @neon
```
