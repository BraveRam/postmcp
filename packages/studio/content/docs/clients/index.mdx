## Overview

Because PostMCP implements the official Model Context Protocol specification over standard `stdio` and `sse` transports, it works seamlessly with every MCP-compatible client, IDE, and terminal agent.

---

## Supported Clients Matrix

| Client | Transport | Turn-1 Hot Tools Supported | Configuration Location |
| :--- | :--- | :--- | :--- |
| **OpenCode** | `stdio` | Yes | `opencode.json` |
| **Claude Code** | `stdio` or `http` | Yes | `.mcp.json` / `claude mcp add` |
| **Codex** | `stdio` or `http` | Yes | `.codex/config.toml` / `codex mcp add` |
| **Cursor IDE** | `stdio` or `sse` | Yes | `.cursor/mcp.json` |
| **Claude Desktop** | `stdio` | Yes | `claude_desktop_config.json` |
| **Windsurf / Cascade** | `stdio` | Yes | `mcp_config.json` |
| **Custom MCP Clients** | `stdio` or `sse` | Yes | Standard JSON-RPC 2.0 client |

## Quick Connection Configuration

Choose your coding agent or editor below to view the configuration snippet:

<Tabs items={['OpenCode', 'Claude Code', 'Codex', 'Cursor']}>
  <Tab value="OpenCode">
    Add to `opencode.json` (or `~/.config/opencode/opencode.json`):

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "firecrawl": {
          "type": "local",
          "enabled": true,
          "command": [
            "bunx",
            "@postmcp/cli",
            "run",
            "https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json"
          ],
          "environment": {
            "BEARER_TOKEN": "YOUR_FIRECRAWL_API_KEY"
          }
        }
      }
    }
    ```
  </Tab>

  <Tab value="Claude Code">
    Add via Claude Code CLI:

    ```bash
    claude mcp add firecrawl -s project -e BEARER_TOKEN=YOUR_FIRECRAWL_API_KEY -- bunx @postmcp/cli run https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json
    ```

    Or add to `.mcp.json` in your project root:

    ```json
    {
      "mcpServers": {
        "firecrawl": {
          "command": "bunx",
          "args": [
            "@postmcp/cli",
            "run",
            "https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json"
          ],
          "env": {
            "BEARER_TOKEN": "YOUR_FIRECRAWL_API_KEY"
          }
        }
      }
    }
    ```
  </Tab>

  <Tab value="Codex">
    Add via Codex CLI:

    ```bash
    codex mcp add firecrawl --env BEARER_TOKEN=YOUR_FIRECRAWL_API_KEY -- bunx @postmcp/cli run https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json
    ```

    Or add to `.codex/config.toml` (or `~/.codex/config.toml`):

    ```toml
    [mcp_servers.firecrawl]
    command = "bunx"
    args = [
      "@postmcp/cli",
      "run",
      "https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json"
    ]
    env = { BEARER_TOKEN = "YOUR_FIRECRAWL_API_KEY" }
    ```
  </Tab>

  <Tab value="Cursor">
    Add to `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "firecrawl": {
          "command": "bunx",
          "args": [
            "@postmcp/cli",
            "run",
            "https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json"
          ],
          "env": {
            "BEARER_TOKEN": "YOUR_FIRECRAWL_API_KEY"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

*(Note: Replace `bunx` with `npx -y` if running on Node.js instead of Bun).*
