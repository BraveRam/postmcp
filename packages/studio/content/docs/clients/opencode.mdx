## OpenCode Integration

OpenCode connects to MCP servers defined in `opencode.json` in your user home directory (`~/.opencode/opencode.json`) or in the root of your project:

### Zero-Install Example (Firecrawl OpenAPI)

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "firecrawl": {
      "type": "local",
      "enabled": true,
      "command": [
        "bunx",
        "@postmcp/cli",
        "run",
        "https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json"
      ],
      "environment": {
        "BEARER_TOKEN": "YOUR_FIRECRAWL_API_KEY"
      }
    }
  }
}
```

*(If running with Node.js instead of Bun, replace `"bunx"` with `"npx", "-y"`).*

### Preset Example (Neon Serverless Postgres)

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "neon": {
      "type": "local",
      "enabled": true,
      "command": [
        "bunx",
        "@postmcp/cli",
        "run",
        "@neon"
      ],
      "environment": {
        "NEON_API_KEY": "${NEON_API_KEY}"
      }
    }
  }
}
```

## CLI Agent Configuration Comparison

Compare how PostMCP connects across your favorite CLI agents:

<Tabs items={['OpenCode', 'Claude Code', 'Codex', 'Cursor']}>
  <Tab value="OpenCode">
    In `opencode.json`:

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "firecrawl": {
          "type": "local",
          "enabled": true,
          "command": [
            "bunx",
            "@postmcp/cli",
            "run",
            "https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json"

    ```
  </Tab>

  <Tab value="Claude Code">
    Terminal command:

    ```bash
    claude mcp add firecrawl -s project -e BEARER_TOKEN=YOUR_FIRECRAWL_API_KEY -- bunx @postmcp/cli run https://raw.githubusercontent.com/firecrawl/firecrawl/refs/heads/main/apps/api/openapi.json
    ```

    Or add to `.mcp.json` in your repository root. See the [Claude Code Guide](/docs/clients/claude-code) for full details.

    Or add to `.codex/config.toml`. See the [Codex Guide](/docs/clients/codex) for full details.

## Why PostMCP Excels with CLI Agents

CLI agents have strict token limits and run in terminal environments where large JSON outputs clutter terminal history. 

By delivering:
1. **Markdown Table Serialization**: Output displays cleanly in terminal logs.
2. **Turn-1 Hot Tools**: The agent executes immediately without wasting prompt turns on tool discovery.
3. **Internal Auto-Pagination**: The agent gets complete results without writing terminal loop scripts.
