## What Are Presets?

A **Preset** is an officially verified, pre-tuned configuration for a popular web service or cloud provider. Presets include:
1. **Full-Fidelity OpenAPI Specification**: Comprehensive parameter validation, types, and operation definitions.
2. **Pre-Tuned Token Diet Rules**: Tailored JSONPath field masks for high-volume endpoints (e.g. `listProjects`, `listCharges`).
3. **Turn-1 Hot Tool Prioritization**: Verified root collection operations flagged for immediate mounting.
4. **Automated Auth & Tenant Mapping**: Standard environment variable mappings (e.g. `NEON_API_KEY`, `STRIPE_SECRET_KEY`).

## Running a Preset

To run any preset via the CLI:

```bash
# Using standard stdio transport
postmcp run @neon

# Using SSE transport with explicit auth
postmcp run @stripe --transport sse --port 3001 --api-key "$STRIPE_SECRET_KEY"
```

To list all available presets from your terminal:

```bash
postmcp presets
```
