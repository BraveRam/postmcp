## Overview

You can persist server configurations, authentication credentials, and custom Token Diet field masks in a configuration file named `postmcp.config.json` in your project root, or specify a custom path via `--config <path>`.

---

## Schema Reference

```json
{
  "spec": "https://api.example.com/openapi.json",
  "baseUrl": "https://api.example.com/v1",
  "transport": "stdio",
  "port": 3000,
  "auth": {
    "bearerToken": "${API_KEY}",
    "headers": {
      "X-Custom-Header": "custom-value"
    }
  },
  "jit": {
    "enabled": true,
    "maxMountedTools": 25,
    "hotToolKeywords": ["project", "user", "organization", "account"]
  },
  "tokenDiet": {
    "enabled": true,
    "maxTokens": 2500,
    "convertToMarkdownTable": true
  },
  "fieldMasks": {
    "listProjects": ["id", "name", "region", "created_at"],
    "getUser": ["id", "email", "role"]
  },
  "dryRun": false,
  "enabledOperations": {
    "deleteUser": false,
    "dropDatabase": false
  }
}
```

---

## Property Details

### `spec`
- **Type**: `string`
- **Description**: Path to a local JSON/YAML file, remote URL, or preset alias (e.g. `@neon`).

### `baseUrl`
- **Type**: `string`
- **Description**: Target upstream API base URL override.

### `transport`
- **Type**: `"stdio" | "http"`
- **Description**: Server communication protocol.

### `port`
- **Type**: `number`
- **Description**: Listening port when using `http` transport.

### `auth`
- **Type**: `object`
- **Properties**:
  - `bearerToken`: Bearer authentication token or environment variable reference (`"${API_KEY}"`).
  - `apiKey`: Object with `{ name, value, in: "header" | "query" | "cookie" }`.
  - `basicAuth`: Basic authentication credentials `{ username, password }` or base64 string.
  - `headers`: Map of static custom HTTP headers.

### `jit`
- **Type**: `boolean | object`
- **Properties**:
  - `enabled`: Enables Just-In-Time dynamic tool routing.
  - `maxMountedTools`: Maximum active tools before dynamic routing kicks in.
  - `hotToolKeywords`: Array of strings used to rank root collections on startup.

### `tokenDiet`
- **Type**: `object`
- **Properties**:
  - `enabled`: Whether token optimization is active.
  - `maxTokens`: Token ceiling per tool response.
  - `convertToMarkdownTable`: Whether arrays of uniform objects are serialized as Markdown tables.

### `fieldMasks`
- **Type**: `Record<string, string[]>`
- **Description**: Map of operation IDs to array of whitelisted property keys to retain in responses.

### `dryRun`
- **Type**: `boolean`
- **Description**: When true, mutation endpoints are simulated without invoking upstream APIs.

### `enabledOperations`
- **Type**: `Record<string, boolean>`
- **Description**: Granular whitelist/blacklist of specific operation IDs.
