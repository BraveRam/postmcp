---
title: postmcp inspect
description: Profile endpoints, evaluate security risk tiers, and calculate token savings before server deployment.
---

## Usage

```bash
postmcp inspect <spec> [options]
```

The `inspect` command analyzes an OpenAPI specification without starting an active server. It prints a detailed structural report showing:
- Total operation count and breakdown by HTTP method.
- Security risk classification for every endpoint (`READ_ONLY`, `MUTATION`, `CRITICAL`).
- Identified root collection operations recommended for turn-1 hot mounting.
- Estimated schema token count and projected savings under each Token Diet level.

---

## Options

| Flag | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `--json` | `boolean` | Output machine-readable normalized AST JSON instead of human-readable summary. | `false` |

---
