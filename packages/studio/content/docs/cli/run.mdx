---
title: postmcp run
description: Start a live Model Context Protocol server from any OpenAPI specification or preset.
---

## Usage

```bash
postmcp run <spec> [options]
```

Where `<spec>` can be:
- A local file path (`./swagger.json`, `./openapi.yaml`).
- A remote HTTP or HTTPS URL (`https://api.example.com/openapi.json`).
- A bundled preset alias (`@neon`, `@stripe`, `@github`, `@supabase`).

---

## Command-Line Options

| Flag | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `-t, --transport <mode>` | `string` | Communication transport: `stdio` or `http`. | `stdio` |
| `-p, --port <number>` | `number` | Port for Streamable HTTP server mode. | `3000` |
| `-b, --base-url <url>` | `string` | Override the upstream API base URL defined in the spec. | Extracted from spec |
| `-H, --header <kv...>` | `string[]` | Pass custom HTTP headers (e.g. `-H "X-Custom: value"`). | None |
| `--bearer <token>` | `string` | Bearer authentication token or `$ENV_VAR`. | Read from env |
| `--api-key <name=value>` | `string` | API key credentials (e.g. `key=val`, `header:key=val`, `query:key=val`). | Read from env |
| `--basic-auth <credentials>` | `string` | HTTP Basic authentication credentials (`username:password` or `$ENV_VAR`). | Read from env |
| `--jit` | `boolean` | Enable Just-In-Time dynamic tool routing with `tool_search`. | Enabled if > 20 tools |
| `--no-jit` | `boolean` | Disable JIT mode and mount all operations immediately. | - |
| `--hot-tool-keywords <k...>` | `string` | Comma-separated keywords to identify turn-1 pre-mounted hot tools. | Domain heuristics |
| `--dry-run` | `boolean` | Intercept mutations and return simulated responses. | `false` |
| `--token-diet` | `boolean` | Enable Token Diet response optimization. | Enabled by default |
| `--no-token-diet` | `boolean` | Disable Token Diet payload pruning and markdown tables. | - |
| `--max-tokens <number>` | `string` | Token ceiling per tool response. | `2500` |
| `--env-file <path>` | `string` | Custom `.env` file path to load. | `.env` |
| `-c, --config <path>` | `string` | Custom `postmcp.config.json` path. | `postmcp.config.json` |

## Examples

### 1. Stdio Transport for Claude Desktop, Cursor, and OpenCode

Stdio is the standard communication transport for desktop AI applications. To launch a server over stdio:

```bash
postmcp run https://api.petstore.com/v2/openapi.json
```

### 2. Streamable HTTP Transport with Custom Port

Streamable HTTP allows remote AI clients, microservices, and web applications to communicate over standard HTTP streams:

```bash
postmcp run @neon --transport http --port 8080 --bearer "$NEON_API_KEY"
```

The Streamable HTTP server exposes a single unified endpoint:
- `http://localhost:8080/mcp`: Handles initialization handshakes, tool executions, and server-sent streaming responses with stateful session management via the `mcp-session-id` header.

### 3. HTTP Basic Authentication

Pass credentials directly or resolve them from the `BASIC_AUTH` environment variable:

```bash
postmcp run https://raw.githubusercontent.com/twilio/twilio-oai/main/spec/yaml/twilio_api_v2010.yaml \
  --basic-auth "AC_ACCOUNT_SID:AUTH_TOKEN"
```

### 4. API Key via URL Query Parameter

For APIs that accept credentials as query parameters (e.g. `?appid=...` or `?api_key=...`):

```bash
postmcp run ./weather-api.json --api-key "query:appid=$OPENWEATHER_KEY"
```

### 5. Overriding Base URL and Setting Token Limit

```bash
postmcp run ./internal-api.json \
  --base-url https://staging.api.internal.net/v1 \
  --max-tokens 4000 \
  --dry-run
```

### 6. Custom Turn-1 Hot Tool Keywords

Override the default keyword ranking heuristic so that operations matching specific domains are pre-mounted on turn 1:

```bash
postmcp run ./logistics-api.json \
  --hot-tool-keywords shipment,parcel,tracking,freight
```
